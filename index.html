ფონტები და სუფთა CSS

ისწავლე ვებგვერდზე ფონტების გამოყენება, CSS-ის დალაგება და კოდის გაუმჯობესება.

მისია 1

ფონტები

  1. body-სთვის გამოიყენე ლოკალური ფონტი, რომელიც @font-face-ითაა გამოცხადებული.
  2. h1-სთვის გამოიყენე Google Fonts-ის სქელი ფონტი.
  3. შეამოწმე, რომ ქართულ ასოებს სწორი ფონტი აჩვენებს და მითითებულია fallback.

მისია 2

კომენტარები

  1. HTML-ში კომენტარით აღწერე გვერდის ძირითადი სექციები.
  2. CSS-ში კომენტარით მონიშნე სტილების ჯგუფები — მაგალითად, სათაური, ნავიგაცია და ბარათები.

მისია 3

AI — კოდის მიმოხილვა

ჩასვი შენი HTML და CSS AI ჩატში და სთხოვე შეამოწმოს სემანტიკა, ხელმისაწვდომობა, მობილურზე ადაპტაცია და ფონტები.

„გააკეთე ჩემი HTML-ისა და CSS-ის code review. მითხარი, რა არის კარგი, რა პრობლემებია და რატომ; შემომთავაზე კონკრეტული გაუმჯობესებები. კოდი არ გადააკეთო — ჯერ მხოლოდ რეკომენდაციები მომეცი.“

მისია 4

GitHub Pages

  1. ატვირთე ფაილები GitHub-ის რეპოზიტორიაში და შექმენი commit.
  2. რეპოზიტორიის Settings → Pages მენიუში ჩართე GitHub Pages.
  3. გახსენი გამოქვეყნებული ბმული და დარწმუნდი, რომ გვერდი მუშაობს.
